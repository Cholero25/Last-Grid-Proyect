# Last-Grid-Proyect

🧑‍💻 User Dashboard Interface
A clean and responsive dashboard interface built using CSS Grid Layout, designed to help users manage their projects, messages, tasks, and announcements in a user-friendly environment.

📸 Preview

🚀 Features
✅ Sidebar navigation with intuitive icons:

Home

Profile

Messages

History

Tasks

Communities

✅ Project cards with action buttons (star, eye, settings)

✅ Announcements section with multiple updates

✅ Welcome header with user profile and avatar

✅ Top buttons for creating, uploading, and sharing content

✅ Built using CSS Grid for layout structure

🛠️ Technologies Used
HTML5

CSS3 (Grid Layout)
